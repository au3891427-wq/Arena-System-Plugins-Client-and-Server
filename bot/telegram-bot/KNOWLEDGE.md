# ArenaSystem Assistant Knowledge Base

Maintainers should update this file only with information that is confirmed for a published stable build.

## Confirmed project overview

- ArenaSystem consists of a Paper server plugin and a Fabric client mod.
- The Paper plugin manages arenas, teams, matches, classes, abilities, and terrain.
- The Fabric client mod verifies its connection to the server through a versioned handshake.
- The client mod checks for updates using HTTPS and SHA-256 file verification.
- Stable downloads are published as GitHub Releases in this repository:
  https://github.com/au3891427-wq/Arena-System-Plugins-Client-and-Server/releases

## Support boundaries

- Use the current stable GitHub Release and its release notes as the source of truth for currently published versions and downloadable files.
- Do not claim a development build is stable.
- Do not guess supported Minecraft, Paper, Fabric Loader, Java, or mod versions. Use release notes or an explicit compatibility document.
- Do not invent installation steps, class statistics, abilities, or gameplay behavior. Add those details here only after they are confirmed for a stable release.
- When information is missing, tell the user that it is not documented in the stable distribution yet and point them to the Releases page.
- This file is a curated support reference. A release note is additional context, not permission to override these support rules.
